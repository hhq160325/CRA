# Favorites Feature

This feature manages user's favorite cars functionality.

## Components

- `favoritesSlice.js` - Redux slice for managing favorites state

## Actions

- `addToFavorites(carId)` - Add a car to favorites
- `removeFromFavorites(carId)` - Remove a car from favorites
- `fetchFavorites()` - Fetch user's favorite cars
- `toggleFavoriteLocal(carId)` - Toggle favorite status locally (optimistic update)

## State Structure

```javascript
{
  favoriteCarIds: [], // Array of car IDs that are favorited
  favoriteCars: [],   // Array of full car objects that are favorited
  loading: false,     // Loading state for async operations
  error: null         // Error message if any operation fails
}
```

## Usage

The favorite functionality is integrated into:

1. **CarDetail component** - Users can click the heart icon to add/remove from favorites
2. **FavouriteCarPage component** - Displays all favorited cars
3. **Car cards** - Heart icons show favorite status and allow toggling

## Implementation Notes

- Uses optimistic updates for better UX
- Reverts changes if API calls fail
- Currently uses mock data - replace with actual API calls when backend is ready
